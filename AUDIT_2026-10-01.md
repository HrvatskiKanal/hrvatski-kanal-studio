# Audit — Hrvatski Kanal Studio

**Date:** 1 October 2026  
**Scope:** `HrvatskiKanal/hrvatski-kanal-studio` — 14 browser-local tools, shared static assets, and user-facing limitations.

## Result

The Studio is now a **browser-local tool lab**: it has no application backend, user accounts, payment flow, advertising SDK, paid API, API keys, or CDN-loaded scripts/styles. The repository has a machine-readable tool registry and agent instructions so future work starts from one canonical location.

> “Gratis” here means the Studio itself does not trigger a paid application service. Browser/device capabilities, an internet connection, and a compatible browser are still required. A server-side multi-platform downloader is intentionally not presented as a Studio/GitHub Pages feature.

## Dependency and privacy boundary

| Component | Source | Cost/privacy position |
|---|---|---|
| QR generation | Local pinned QRCode 1.5.4, MIT | No network request by Studio |
| PDF generation | Local pinned jsPDF 2.5.0, MIT | No network request by Studio |
| Browser transcription runtime | Local Transformers.js and ONNX Runtime assets | No paid API and no Studio upload; first file transcription downloads an open model once into browser cache |
| Text reader | Native Web Speech API | Browser/device implementation; no Studio server |
| All other Studio tools | Browser Canvas/File/Blob APIs | Local processing |

## Guardrails for future additions

- Browser-local utilities go in this repository, under `tools/`.
- Update `TOOL_REGISTRY.json`, `AGENTS.md`, `TOOL_LAB.md`, `README.md`, `app.js`, and tests in the same change whenever inventory changes.
- Server-only capabilities must state CPU, disk, bandwidth, hosting, and third-party boundaries. They must not be represented as a static GitHub Pages feature.
- Old copies of the main site are not an approved location for new tools; they remain visible in the Tool Lab registry until a separate deployment/redirect audit supports a safe migration.
