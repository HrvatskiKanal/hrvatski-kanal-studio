# Sigurnosna politika

## Podržana verzija

Podržava se trenutačna verzija na grani `main` repozitorija `HrvatskiKanal/hrvatski-kanal-studio`.

## Prijava sigurnosnog problema

Molimo prijavite ranjivost privatno putem GitHubove opcije **Security → Advisories → Report a vulnerability**. Nemojte objavljivati neispravljene ranjivosti kao javni issue niti slati stvarne API ključeve, lozinke ili osobne podatke u javnim objavama.

U prijavu uključite pogođenu datoteku ili verziju, korake za ponavljanje problema i mogući učinak. Ako je moguće, koristite siguran dokaz koncepta bez stvarnih tajni i bez pristupa tuđim podacima.

Vlasnik će prijavu pregledati čim to bude razumno moguće i po potrebi nastaviti razgovor kroz GitHubov privatni kanal. Ne obećava se fiksni rok odgovora.

Za obične funkcionalne greške koje nisu sigurnosna ranjivost koristite GitHub Issues.
