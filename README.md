# Hrvatski Kanal Studio

Jednostavan web app sa svim alatima za obradu slika, teksta, PDF-a i dodatnih malih alata.

## Struktura

- `index.html` - landing page s pregledom alata
- `styles.css` - zajednički dizajn
- `app.js` - navigacija i podaci o alatima
- `tools/` - pojedinačne stranice alata

## Alati

- Brisanje pozadine
- Konverter slika
- Brojač teksta
- Čitač teksta
- Paleta boja
- QR kod generator
- Optimizacija slika
- Slike u PDF
- Spajanje slika
- Okvir i sjena
- Vodeni žig
- Zamućivanje pozadine

## Napomena

Svi alati su dizajnirani kao lokalni browser-based alati, bez plaćenih API-jev i bez dodatnih komplikacija.
